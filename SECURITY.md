# Security Policy

## Reporting a Vulnerability
We take the security of the Mumbai Local Train Delay Tracker project seriously. If you discover a security vulnerability, please report it privately rather than opening a public issue.

- **Email:** Report security concerns directly via private message on GitHub or email.
- **Scope:** Vulnerabilities in API endpoints, database injection risks, or scraper dependency flaws.
- **Response Timeline:** We aim to acknowledge reports within 48 hours and provide a patched resolution as quickly as possible.
